# lhg-budget：记账预算专家，导入即出报表

> ⚠️ **合规声明（首屏置顶）**：本工具仅为**记账与预算分析助手**，**不构成任何投资建议**；涉及投资决策请咨询持牌专业人士。
>
> **一句话介绍**：给 AI 编程助手装上"记账预算专家"——银行/支付宝/微信账单 CSV 一句话导入 → 自动分类 → 可视化月度报表 → 预算超支预警；**零配置，导入即出报表**，并有投资建议关键词硬门全程护航。
>
> **一键安装**：在 Claude Code 里运行
> ```
> /plugin marketplace add lhg-plugs/lhg-budget
> /plugin install lhg-budget@lhg-plugs
> ```

## 它是什么

`lhg-budget` 是一个 Claude Code 插件（plugin 为主、skill 为辅），专治小白"记账习惯养成难"：

- **4 个命令**（小白入口）：`budget` 一条龙（导入→分类→报表→预警），`import` 账单导入专精，`report` 月度报表专精，`audit` 账单体检
- **4 个平台中立 skill**（方法论，可移植到豆包/Workbuddy 等 agent 平台）：账单导入五步法、自动分类四步法、月度报表五步法、预算偏差预警五步法
- **2 个专家 agent**：账单导入专家、预算审计专家
- **1 个合规硬门 hook**：写入文件命中投资建议关键词（买入/加仓/必涨/抄底/重仓/推荐买等）直接拦截，可一键关闭
- **35 条确定性审计规则**：纯 Python 标准库、零第三方依赖，覆盖编码/CSV结构/金额/日期/分类/交易异常/预算/合规 8 大类

## 快速上手（30 秒）

```
# 1. 把账单 CSV 丢给它（一句话也行）
/lhg-budget:budget ~/Downloads/alipay-202610.csv

# 2. 看预览，确认导入
# 3. 拿到月度报表 + 预算预警
```

就这么简单。编码探测（UTF-8/GB18030）、分隔符识别、支付宝/微信/银行列名映射、去重——全自动。

## 命令一览

| 命令 | 干什么 |
|---|---|
| `/lhg-budget:budget` | 主流程：导入→分类→报表→预警一条龙 |
| `/lhg-budget:import` | 账单 CSV 导入：探测→清洗→去重→预览确认→落盘 |
| `/lhg-budget:report` | 月度报表：收支总览、分类占比、趋势、储蓄率、异常点 |
| `/lhg-budget:audit` | 账单体检：35 条规则审计，blocker 清零才放行 |

## 审计规则（35 条，8 大类）

| 大类 | 条数 | 查什么 |
|---|---|---|
| 编码 | 2 | 乱码文件、非 UTF-8 编码 |
| CSV 结构 | 4 | 分隔符、列数不一致、空文件、重复表头 |
| 金额 | 6 | 金额列识别、方向推断、符号清洗、解析失败、方向颠倒 |
| 日期 | 4 | 日期列识别、格式混杂、跨月、未来日期 |
| 分类 | 5 | 覆盖率、无分类列、分类过粗、命名不规范 |
| 交易异常 | 6 | 异常大额、重复导入、跨文件重复、退款对、超总预算 |
| 预算 | 6 | 分类超支、总额超支、缺预算配置、使用过快 |
| 合规 | 2 | 投资建议关键词拦截、报表合规声明检查 |

跑：`python3 scripts/audit/budget_audit.py --target <账单目录> --format json`
退出码：2=有 blocker，1=有 warning，0=干净。

## 什么时候用 / 什么时候不用（FAQ）

**什么时候用**
- 导出过支付宝/微信/银行账单，想一眼看懂"钱花哪了" → 用。
- 每个月都觉得"钱不知道去哪了"，想养成记账习惯但嫌麻烦 → 用（导入即出报表，爽感拉满）。
- 想给某个分类设预算、超支自动预警 → 用。
- 团队/家庭要一份干干净净的支出月报 → 用。

**什么时候不用**
- 想问"买哪只基金/股票" → 不用。本插件只记账，不管投；投资建议是红线，问就是"请咨询持牌专业人士"。
- 只有截图/PDF 账单，没有 CSV → 先转成 CSV 再来（或手工录关键行）。
- 要做的是"下个月钱怎么分配"的深度理财规划 → 去隔壁 [lhg-money-plan](https://github.com/lhg-plugs/lhg-money-plan)（理财规划向）；本插件是"账单导入执行向"，两者互补。

## 合规设计：三层防护

1. **声明置顶**：README 首屏、每个 SKILL.md 开头、每条命令输出末尾，都有显著的合规声明。
2. **硬门拦截**：`hooks/pre_write_advice_gate.py` 在写入时扫描投资建议关键词，命中直接 deny；逃生：`LHG_BUDGET_HOOKS_OFF=1`。
3. **审计兜底**：`B-INV-001`（投资建议表述→blocker）、`B-CMP-001`（报表缺合规声明→warning）。
