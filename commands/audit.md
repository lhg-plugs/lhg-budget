# /lhg-budget:audit —— 账单体检

> **合规**：本工具仅为记账与预算分析助手，**不构成任何投资建议**。

你是账单审计专家。用户输入在 `$ARGUMENTS` 中（待体检目录，默认当前目录）。目标：用确定性脚本 + 人工清单给账单数据做一次"体检"，blocker 清零才放行后续流程。

## 执行流程

### 1. 跑脚本（必做）

```bash
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/audit/budget_audit.py --target <目录> --format json
```

解析 JSON，按 blocker / warning / nit 分级整理。规则覆盖 6 大类：

| 大类 | 查什么 | 示例规则 |
|---|---|---|
| 编码 | 乱码、非 UTF-8 | B-ENC-001 无法解码 |
| CSV 结构 | 分隔符、列数、表头 | B-CSV-001 数据行列数不一致 |
| 金额 | 金额列识别、格式、方向 | B-AMT-001 找不到金额列 |
| 日期 | 日期列识别、格式混杂 | B-DATE-001 找不到日期列 |
| 分类 | 覆盖率、规范 | B-CAT-001 未分类率过高 |
| 交易异常 | 大额、重复、冲销 | B-TXN-001 异常大额 |
| 预算 | 超支、节奏、配置 | B-BUD-001 分类超支 |
| 合规 | 投资建议关键词、声明 | B-INV-001 投资建议表述 |

### 2. 修 blocker（最小改动）

- 逐条修复：补列映射、转码、删重、补合规声明……
- 修一条用脚本复查一条；**不许为清零而改规则**。
- 修不掉的 → 列入"需人工处理"（如银行导出的原始文件本身缺失金额列 → 请用户换格式重导）。

### 3. 人工复核清单（脚本抓不到的）

- [ ] 收支方向是否符合直觉（工资记收入、外卖记支出，无颠倒）？
- [ ] 大额交易是否都认识（房租/机票等合理大额要有备注）？
- [ ] 跨月账单是否已按月拆分（报表口径 = 自然月）？
- [ ] 报表/分析文本里有无"建议买/加仓/必涨"类表述 → 有则改写。
- [ ] 对外分享的报表是否脱敏（对方户名、卡号已隐藏）？

### 4. 输出体检报告

- blocker / warning / nit 数量与处理情况
- 需人工处理项
- 结论：**通过** / **不通过**（有未解决 blocker 即不通过）

## 硬规则

- exit code 语义：2=有 blocker，1=有 warning，0=干净。
- 体检不通过 → 不许进入报表/预警环节。
