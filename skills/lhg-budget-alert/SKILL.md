# lhg-budget-alert：预算偏差预警五步法

> **合规声明**：本方法论仅用于记账与预算分析，**不构成任何投资建议**；涉及投资决策请咨询持牌专业人士。

## 1. 何时使用 / 何时不用

**用**：月度报表已出，用户想知道"这个月有没有花超、哪个分类要收一收"——预算制定、月中检查、月末复盘都适用。

**不用**：
- 还没有至少 1 个月的真实账本 → 先记账（`lhg-budget-import`），没有历史数据的预算是拍脑袋。
- 用户要的是"钱投哪" → 不做。本方法论只管"花"，不管"投"；投资建议是红线。
- 用户明确说"这个月就是要放开花" → 尊重，预警降级为只记录不打扰。

## 2. 输入与输出

**输入**：`ledger-YYYYMM.csv` + `budget.json`（没有就按第 3 步生成默认版）。

`budget.json` 格式：

```json
{
  "month": "2026-10",
  "budgets": {"餐饮": 3000, "交通": 800, "居住": 3500, "消费": 1500, "其他": 1200},
  "total": 10000,
  "note": "total 为月度总预算上限"
}
```

**输出**：三级预警清单（已超 / 快超 / 正常）+ 一句话行动提示（只描述事实，不给理财建议）。

## 3. 分步方法论

### 第 1 步：预算从哪来（三档，按用户成熟度选）

1. **零配置档（默认）**：有历史账本 → 取近 3 个月同分类均值 × 1.0 作为本月预算，生成后请用户确认一遍。小白第一次用，直接给他"能用的数字"而不是"填空题"。
2. **50/30/20 档**：用户想"科学一点" → 必要开支（居住+餐饮+交通）50%、想要开支（消费+社交）30%、储蓄 20%。按税后月收入换算成各分类金额，问用户微调。
3. **信封档**：用户自控力弱 → 按分类设"信封"，花完即停，不挪用。适合"每个月餐饮必超"的人，先治超支最多的那一个分类。

无论哪档：**预算数字必须用户点头**，助手不许单方面定一个"合理预算"就开跑。

### 第 2 步：实际 vs 预算（口径对齐是关键）

- 实际支出口径与报表一致（不含内部转账、退款已冲减）。
- 对比维度：各分类实际 / 各分类预算、总支出 / total。
- 房租这类"月初一次性"大额 → 单独标注"固定支出"，不计入"节奏预警"（否则每月 1 号就报警，狼来了）。

### 第 3 步：节奏预警线（月中检查用）

设 `进度 = 当月已过天数 / 当月总天数`，`使用率 = 分类实际 / 分类预算`：

| 情况 | 级别 | 话术（事实型） |
|---|---|---|
| 使用率 ≥ 100% | 🔴 已超 | "餐饮已用 112%（¥3,360/¥3,000），超 ¥360" |
| 使用率 ≥ 80% 且进度 < 50% | 🟡 快超 | "交通已用 85%（¥680/¥800），这个月才过去 12 天" |
| 使用率 ≥ 80% 且进度 ≥ 50% | 🟢 正常偏高 | "消费已用 82%，节奏基本同步" |
| 使用率 < 80% | 🟢 正常 | 不打扰 |

**不骚扰原则**：一次预警只输出一张清单；用户没问，不每天追着报；"正常"的不逐条报，只给总数。

### 第 4 步：超支归因（只摆事实）

对 🔴/🟡 分类，列出该分类 Top3 单笔 + 笔数变化（如"餐饮 41 笔，比上月多 9 笔"）。归因止于数据层面（"多了 9 笔外卖"），**不延伸成生活建议**（不说"你应该自己做饭"），更不许滑向理财建议。

### 第 5 步：月末复盘（闭环）

- 本月超支分类 → 下月预算是否上调/保持，**由用户定**，助手只摆出"上调到 ¥X 则总预算变为 ¥Y"的算术。
- 连续 3 个月同分类超支 → 提示"这个预算可能不符合你的实际生活，要不要重定？"（提示一次，不说教）。
- 复盘结论写回 `budget.json` 的 `note`，下个月有据可查。

## 4. 反模式（不要这样做）

- ❌ 没有用户确认就定预算 → 预算是承诺，承诺不能代签。
- ❌ 预警话术带评判（"你又乱花钱了"）→ 只报数字，把解读留给用户。
- ❌ 把"超支"和"投资建议"混在一起（"餐饮超了，建议买货币基金锁住钱"）→ 红线，超支只谈花。
- ❌ 节奏预警不看进度 → 月初 80% 和月末 80% 是两回事。
- ❌ 固定支出（房租）参与节奏预警 → 每月 1 号准时误报，用户会关掉预警。

## 5. 自检与反馈

**质检门**：
1. 预算每个数字都有用户确认记录（对话里或 budget.json 的 note）？
2. 预警清单三级是否齐全（已超/快超/正常），有无漏报超支分类？
3. 话术里有无"建议/应该/最好"开头的理财建议句 → 有则改写为事实描述。
4. 固定支出是否排除在节奏预警外？
5. 输出末尾有合规声明？

**标准冒烟用例**：`fixtures/csv-good/` + `budget.json`（预算充足）应零 blocker、无超支预警；把某分类预算调低后重跑，应触发 B-BUD-001（分类超支 blocker）。

**一键反馈**：想要新的预算框架或预警节奏 → 提 issue（标题：`[alert] <建议>`），说明适用人群。

## 附：预算调整记录模板

每次调预算都留一行记录，下个月不再拍脑袋：

```json
{
  "month": "2026-11",
  "budgets": {"餐饮": 3200, "交通": 800, "居住": 3500, "消费": 1500, "其他": 1000},
  "total": 10000,
  "changes": [
    {"category": "餐饮", "from": 3000, "to": 3200,
     "reason": "10 月实际 ¥3,360，用户确认上调", "by": "用户 2026-11-01 确认"}
  ]
}
```

字段要求：`from/to` 必填，`reason` 写事实（上月实际数），`by` 写"谁确认的+日期"。没有用户确认的调整 = 无效调整。

## 附：常见问答

**Q：预算老是超，是不是我定的太低？**
A：看连续 3 个月的数据：3 个月都超同一分类 → 预算不符合实际，上调；偶尔超 → 那个月有特殊情况，不调。不要一个月超就调，预算会一路水涨船高。

**Q：能不能不设分类预算，只设总额？**
A：可以，但效果打折。总额只告诉你"超了"，分类告诉你"哪超了"。折中方案：只给最爱超的 2~3 个分类设预算，其余不管。

**Q：收入不稳定（自由职业），怎么设预算？**
A：按"近 3 个月最低月收入"定总预算，预算 = 生存线思维。多出来的收入月 → 直接进储蓄，不追加预算。

**Q：预警能不能每天推？**
A：不建议。预算是月尺度的事，日推只会让人麻木然后关掉。固定节奏：每月 1 号定预算、15 号看一次节奏、月末复盘。三次够了。

**Q：两个人一起记账（一家子）怎么办？**
A：账本分开记（每人一个 ledger 文件），报表时合并看"家庭总账"。分类树共用一套，预算按人设。不要把两个人的账混在一个文件里，对账会疯。

## 附：新用户 30 天上手路径

- **第 1 天**：导出上个月账单 → 跑导入 → 看第一份月报（别管预算）。
- **第 7 天**：补完待确认分类，覆盖率 ≥ 90%。
- **第 15 天**：用零配置档生成第一个预算，确认数字。
- **第 30 天**：看第一次节奏预警，月末复盘调预算。

**核心**：先有账本，再有预算。顺序反了（先定预算再记账），小白坚持不过两周。

**最后一条**：预算是工具，不是审判。连续两月没达标也别自责，
先问"预算数字对不对"，再问"执行行不行"。顺序错了，工具就变成焦虑源了。
